Methodology & Data Integrity

📡 Data Collection

All aircraft were logged equally — no cherry-picking. Every aircraft on radar at the time of a biometric event was logged to that event. Multiple aircraft share a single biometric event (many-to-one), captured in unified_biometric_batch_events.aircraft_in_correlation_window.

💓 Biometric Sources

  • WHOOP wearable (HRV, resting HR, strain, recovery, sleep)
  • Welltory app (stress score, HRV, physiological variability)
  • Integrated monitoring (cortisol, adrenaline, blood pressure)
  • All biometrics are personal real-time data from subject Joseph Nipper

✈ Flight Data Sources

  • ADS-B live tracking (xxb_live: 327K records)
  • MLAT telemetry (xxb_unknown: 1.23M records)
  • Low-altitude suspicious (xxb_low_alt_suspicious: 90K)
  • Zero-registration ghost aircraft (raw XXB: 2K ICAO-hex)
  • Tier-2 shell aircraft (xxb_tier2_shell: 2.7K)
  • Watchtower master forensic bridge: 1,763,755 total records

🔬 Bradford Hill Criteria

  • Strength — Magnitude of biometric deviation
  • Consistency — Repeated across multiple encounters
  • Temporality — Aircraft present before biometric event
  • Biological Gradient — Dose-response (altitude/proximity)
  • Plausibility — Known surveillance mechanisms
  • Specificity — Particular aircraft types/patterns

⏱ Timestamp Normalization

Key fix: confirmed_biometric_correlations.biometric_timestamp stored as TEXT — normalized via CAST to TIMESTAMPTZ. All 12 source tables normalized to UTC. Time windows: 5-minute for threshold collapses, 300-second batch window for unified events.

🔒 Chain of Custody

All records protected by SHA-256 Merkle chain. Each biometric reading, flight detection, and correlation event carries an independent cryptographic hash. Archive spans 17M+ records across 900+ PostgreSQL tables on Neon/Azure West US 3.

👻 Phantom / Masked Aircraft

332 biometric events where aircraft transponders were masked or spoofed, captured in phantom_stress_unmasking and phantom_stress_reconciliation. ICAO hex spoofing detection includes altitude masking and registration impersonation patterns.
